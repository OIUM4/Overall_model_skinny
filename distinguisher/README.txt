The different folders are:
- `probability`: the code to check the probabilities of the distinguishers.
-  `SKINNY-n-tn`:
      - "***.json" : the output files of distinguishers used in our article.
      - "***.pdf" : the abbreviated pictures of our attacks which is generated by the automated tool.
      - "***.tex" :  a file  to generate the abbreviated pictures by latex tool.
      - "***.html" : an HTML visualization converted by the Step 1 JSON solution.
